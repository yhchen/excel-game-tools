# Type Matrix Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `testcase` workbook and six negative fixtures so `npm test` executes integer widths, `TStruct`, `TTranslate`, flag enums, `SheetName.ColumnName`, and both `DVAL`/`TCustom` orders.

**Architecture:** Success data lives in `testcase/TypeMatrix.xlsx` and is exported by the existing `src/config_tpl.json` run inside `scripts/verify-fixtures.js`. Failure data lives in `test/fixtures/negative/*.csv`, generated by `test/fixtures/scripts/generate-fixtures.js`, and is asserted by the existing loop in `test/integration/cli-fixtures.test.js`. No product source changes.

**Tech Stack:** TypeScript CLI, Node 22 `node:test`, SheetJS `xlsx`, existing fixture generator.

**Spec:** `docs/superpowers/specs/2026-11-13-type-matrix-coverage-design.md`

## Global Constraints

- Do not modify `src/` or `TypeDef/`.
- Do not add a test runner, coverage dependency, or npm script.
- `testcase/` must keep exporting with exit code 0.
- `ushort` upper bound in the fixture is 32768.
- Empty `CustomThenDval<!N>` exports 5. Empty `CustomWrapDval<!N>` fails.
- `TCustom` wrapped around a sheet column uses `def.Internal.TryColumnTypeTranslate`.

## Review Focus

- Empty `CustomThenDval<!N>` must export 5, because the `DVAL` flag is set on the wrapper.
- Empty `CustomWrapDval<!N>` must fail with the empty-value error, because `TCustom(int.DVAL(5))` does not set the flag.
- A trailing empty token on a `TObject` field of `TCustom(int.DVAL(5))` must fail numeric parsing.
- An empty `TTranslate(int, n => n * 10)` cell must export 0, not a translated value.
- `ushort` 32768 must pass. The type comment says 65535, and the code does not.
- Flag enum export must contain `[ProtoContract, Flags]`, and `PointStruct` must be a C# `struct`.
